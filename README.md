# Lab 1B — Dataset Package

The dataset contains retail transactions for three branches during February, March, and April 2026.

Transaction sources:
- Cali: CSV
- Bogotá: JSON
- Medellín: XML

Reference sources:
- Products
- Stores
- Promotions
- Monthly targets

The files include a small number of intentional quality problems. Students must profile, clean, harmonize, integrate, validate, and produce one unified analytical CSV.
